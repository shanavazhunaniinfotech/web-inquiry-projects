    04 · Before we start

    No surprises later.

    Six things worth knowing now, so the quote covers the complete build and not just the visual layout.

    Checkout

    Changing the checkout page itself needs Shopify Plus. The cart, cart drawer and everything before checkout can be customized on any plan.

    Free gifts

    The gift tiers display natively. To make a gift free in the cart, add a "Buy X get Y" automatic discount. It takes 5 minutes and I can set it up.

    Subscriptions

    The refill toggle works with Shopify Subscriptions (free), Recharge, Loop or Skio. Just tell me which one you use.

    Reviews

    Ratings and review sliders can be static blocks you edit, or pull from your review app. Static blocks load faster and match the reference exactly.

    Bundle apps

    Kaching Bundles is installed on all four stores, but the buy boxes don't depend on it. I build bundles from your variants, with no monthly fee.

    Original content

    The first version uses the reference text and images so you can compare side by side, as you asked. Swap in your own before launch, since that content belongs to those brands.
