    What you just tried, and how it works in Shopify

    Offer tiers are blocksAdd, remove or reorder tiers. Each one points at a product variant, so prices always come from Shopify and are never typed into the code.
    Prices calculate themselvesPer-bag price, savings badge, compare-at price and button price all update from the selected variant.
    Gifts unlock by tierEach gift has an "unlocks from offer #" setting. It can add a real gift product to the cart, made free with an automatic discount.
    Native subscriptionsThe refill toggle reads Shopify selling plans, so it works with Shopify Subscriptions, Recharge, Loop or Skio.
    Separate desktop and mobile settingsHeading size, image sizes, spacing and columns each have their own desktop and mobile setting, as you asked in your brief.
    No app, no monthly feeIt's plain Liquid, CSS and JavaScript in one section file. It doesn't affect the rest of your theme.

    Before we start

    Things you should know up front

    • CheckoutChanges to the checkout page itself need Shopify Plus (Checkout Extensibility). Cart, cart drawer and everything before checkout can be fully customized on any plan.
    • Free giftsThe gift tiers display natively. To make a gift free in the cart, add a "Buy X get Y" automatic discount in Shopify admin. It takes 5 minutes and I can set it up.
    • SubscriptionsThe refill toggle reads Shopify selling plans, so it works with Shopify Subscriptions (free), Recharge, Loop or Skio. Tell me which one you use.
    • ReviewsStar ratings and review sliders can be static blocks you edit, or pull from your review app (Judge.me, Okendo, Loox…). Static blocks load faster and match the reference exactly.
    • Bundle appsKaching Bundles is installed on all four stores, but the buy boxes you see don't depend on it. I build bundles from your product variants, with no monthly fee.
    • Original contentAs you asked, the first version of each page uses the reference text and images so you can compare it side by side. Replace them with your own before launch, because that content belongs to those brands.
