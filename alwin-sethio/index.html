      Why the calendar "comes and goes"

      1. Your homepage is cached by SiteGround.That's good for speed. But the cached homepage also contains the booking form, with a WordPress security token inside it.
      2. That token expires after 12–24 hours.Visitors keep getting the old cached page, so their booking requests can be refused until the cache refreshes. Then it suddenly "works again".
      3. The calendar is slow to answer (1–3 seconds per month).When a request fails or times out, the custom calendar shows every date as grey.
      4. The fix:Exclude the booking form from page caching (or load a fresh token on page load), speed up the availability check, and add an error message and retry instead of greying out the whole calendar.

      Read-only tool. It only reads your public availability data, the same data your booking page loads. It never creates bookings or changes anything on your site.
